# Portable Nectar Rack
*by MonoChaos*

---

Portable Nectar Rack is a sims 3 custom object script. The resulting object can be carried in the sim's inventory and hold nectar bottles while out adventuring. The goal is not to replace the need for at home nectar racks but instead to add a portable version that freezes appreciation/depreciation until the sim gets home from the vacation.

---
## Object Interactions
### Open
Opens the object's inventory
### Stock Wtih Nectar
Moves all nectar bottles in the sim's inventory into the object's inventory
### Take All Nectar
Moves all nectar bottles in the object's inventory into the sim's inventory
## Other Features
- Can be put in sim inventories
- Only valid contents is nectar bottles
- No max amount of nectar bottles
